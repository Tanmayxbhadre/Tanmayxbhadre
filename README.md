## Currently Building

### [IslandFlow](https://github.com/Tanmayxbhadre/IslandFlow) — macOS Dynamic Island utility

> A native macOS app that brings a fluid, context-aware floating surface to the MacBook notch. Handles media control, volume/brightness HUDs, battery monitoring, and system notifications — all anchored to the camera notch like Apple's Dynamic Island.

**What makes it interesting:**
This isn't a menu bar app. IslandFlow is a precision overlay built directly on AppKit and SwiftUI — with real hit-testing geometry, pass-through click regions, CoreAudio integration, and a state machine for hover interactions. Every interaction is designed to get out of the way.

**Status:** UI/UX refinement · Core hardware managers in production  
**Stack:** `Swift` · `SwiftUI` · `AppKit` · `CoreAudio` · `IOKit` · `ServiceManagement`
